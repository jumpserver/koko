# dbkit：WebCLI 与 WebGUI 的数据库公共层

这是一个只依赖 Go 标准库的独立 Go module。WebCLI（tools/usql）和 WebGUI（pkg/chen）分别单向依赖它，不互相导入，不需要 go.work，也不共享会话或驱动注册表。以后 Magnus 可以作为另一个适配器接入，本次没有改动代理。

| 包 | 负责 | 不负责 |
| --- | --- | --- |
| dialect | 产品和租户方言标识，区分 SQL 方言与传输协议 | 驱动注册、资产协议映射、入口支持列表 |
| sqlanalysis | Analyzer 的输入、语句/投影/来源候选、字节位置与诊断 | 连接、执行、授权；解析成功也不等于语句只读或字段来源已证实 |
| catalog | 在授权范围内列出关系和列的 Reader 契约，以及作用在调用方连接上的固定版本探测 | 接收任意 SQL、持有 DSN、开关连接、跨账号缓存 |
| masking | 按顺序编译字段规则，匹配来源名或结果标签，执行 Unicode 文本变换 | 获取策略、决定来源未知时如何处理、转换驱动值、渲染结果 |

目前两端共用脱敏匹配与变换；WebGUI 保留原解析器与目录实现，WebCLI 仍用各驱动已有的目录功能。两端也复用了 MySQL 兼容版本查询。没有增加后台查询、额外连接或新的字段溯源结论。

后续接字段溯源时，解析器先给出候选表和投影，再由调用方注入的 catalog.Reader 在该会话的数据库和 schema 中验证；歧义、无权限、超时都应保留为未知。若需要单独的只读元数据连接，由入口按同一资产、账号和数据库创建、限制权限和超时并关闭；临时表、未提交 DDL 或会话状态不能在独立连接中重现时，不应拿别的会话结果当依据。公共层不接收连接令牌，也不决定产品对未知结果的处置策略。
