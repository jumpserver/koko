# Koko TUI

普通 SSH 登录现在进入 TUI。使用 tview v0.42.0、tcell v2.8.1，以及仓库已有的 libghostty 终端模拟器。所有窗口、标签和输入处理运行在 Koko 服务端；用户无需安装 Herdr、tmux、终端插件或特殊字体。

## 布局与主题

- 顶部导航栏保留圆角边框，产品标题左对齐并使用主题色；顶部保留一行外部留白，导航栏为三行高度：上边框、居中文字、下边框；窄屏两行内容时为四行，上下保持对称。终端低于 24 行时收紧列表底部留白，保证资产行可见。右侧依次为语言、主题、`name(username)`，以 `|` 分隔。日期显示 `YYYY-MM-DD HH:mm:ss`（每秒更新），在右侧日期区域内垂直居中，与左侧快捷键文字区对齐。
- 顶部导航栏下常驻一行标签栏，从资产面板图标开始与上方导航栏标题、下方区域内文案对齐，保留相同的左侧内边距，标签之间用 `│` 分隔。第一个标签为「资产面板」，编号 `0`；会话依次编号 `1`–`9`。`Option/Alt+数字` 直接切换并短暂显示全部编号；编号使用主题色下划线，仅当前标签图标使用主题色，其余文案保持原样，均不加粗，平时将编号所需空间保留在标签末尾，切换编号模式时标签宽度不变；`Ctrl+]` 可持续显示编号，随后输入数字切换。普通终端不会报告单独 Option 的按下和松开，因此无法通用地实现仅按住 Option 显示；macOS 客户端需要将 Option 配置为 Alt/Meta。标签超宽时用方向键、滚轮或更多会话下拉选择，当前标签自动滚入可见范围；普通状态仅当前标签图标使用主题色，文字不高亮、不绘制底部线；键盘导航焦点使用文字下划线。
- 资产面板左侧默认宽 40 列，组织和树共用一个外框；企业版上方显示已验证的用户组织选择器，组织与树之间的横线贯穿左侧外框，社区版完全省略组织区域。树类型名称与组织名称使用相同文字颜色；树类型区域与组织区域均为两行高度：一行控件、一行贯穿左右且与外框相接的分割线。树头左侧为树类型下拉，仅有授权树、类型树和收藏树；右侧为 `z` 折叠 / 展开与 `u` 刷新按钮，按钮整体靠右，最右侧 u 与节点区 e 位于同一列。分割线保持完整，不嵌入文字；首个可见节点同一行的右侧显示 `e`，预留间距避免覆盖节点名称和数量；按 e 或点击该提示直接聚焦节点区。树类型下拉菜单左边框与当前树名称起点对齐。当前组织与树类型名称保持整体底色，聚焦时通过文字与边框颜色提示，不绘制背景色块。多层展开时第一次折叠仅保留第一级 API 节点展开，再次点击全部折叠；全部折叠后点击展开恢复第一级。`-` 执行分级折叠，`+` 展开第一级，子节点按可见范围分批获取。
- 授权树直接显示 API 返回的顶层节点、名称和层级，不额外显示「全部资产」父节点；方向键、Home/End、滚动与分批计数均按可见节点计算。
- 右侧资产区使用圆角边框，左上角嵌入 `a · /根节点 / 完整路径`（默认范围为 `/全部资产`），快捷键 a 高亮；路径对应已加载的节点，移动树光标不会改变它。右侧上方单独放置带圆角边框的搜索框和 `↻ r` 刷新按钮，下方留一行间距再放资产列表；列表使用完整独立外框，不包含搜索栏；表头与上边框间留一行空白，窄屏收紧底部分页留白以保留资产行。刷新保留当前节点、已提交查询与页码，仅重新请求资产列表。输入时保留现有结果，只有 Enter 才从第一页应用新查询，焦点留在搜索框，按 ↓ 进入列表首行；搜索框未聚焦时显示 `/ 搜索` 前缀，聚焦后隐藏，失焦后恢复；聚焦时使用闪烁竖线光标，Enter 提交查询。右侧搜索当前节点的资产，显示名称、地址、平台和备注；资产名称最多占 30 列，剩余空间留给备注。分页栏与表格间留一行空隙，靠近面板底部，只有多页资产才显示分页按钮。只有一个可用授权账号时，按回车直接以默认可用协议进入连接标签，仍执行凭证、ACL 与审批流程；多个账号时使用单边框选择弹层，仅有多个协议时显示协议选择器。
- 石墨灰底色、暖灰白正文、柔和青灰点缀；直接选用 xterm 256 色调色板中的颜色，避免普通 SSH 客户端把低饱和色映射为鲜艳色块。工作区、所有区域和搜索框使用统一背景色，选中行使用灰阶高亮，未聚焦的选择降低亮度，当前焦点用青灰细线指示。所有窗口统一细圆角边框，不随焦点切换成双线框。面板增加内边距和纵向留白，表格列间统一留空。账号弹窗沿用同一套间距和焦点样式。工作区与连接终端共享主题，远端程序指定的 ANSI 颜色保留；无需真彩色或特殊字体。
- 树和表格独立垂直滚动；表格按列水平滚动。滚轮滚动树时，导航光标跟随可见范围，避免时钟或数量更新把视口拉回旧光标；`Home/End` 同时移动光标与视口。长文本按终端列宽省略，节点数量保留在末尾，零资产显示 `(0)`；`F4` 打开完整文本并支持纵向滚动。树宽度可用 `<` / `>` 或拖动右侧边框调整；`Ctrl+B` 隐藏 / 恢复树。
- 最小布局为 72 列 × 20 行。窗口过小时显示尺寸提示，恢复尺寸后继续原状态。最大绘制尺寸限制为 500 列 × 200 行。

## 操作

| 场景 | 键盘 | 鼠标 |
| --- | --- | --- |
| 切换区域 | `F1` 组织（仅企业版）、`F2` 树、`F3` 资产列表；搜索输入和下拉菜单内同样有效 | 点击区域 |
| 切换树 | `t` 直接展开下拉；`1` / `2` / `3` 直接切换 | 点击树头类型下拉 |
| 切换组织（企业版） | `o` 直接展开下拉，数字或方向键选择；包含全局组织 | 点击组织选择器 |
| 所有可操作控件 | `Tab` / `Shift+Tab` 正向 / 反向循环 | 点击控件 |
| 快捷键帮助 | `F10` 或 `?`；输入框内用 `F10` | — |
| 树导航 | `e` 聚焦节点区；`↑↓`、`Home/End`、`PgUp/PgDn` | 滚轮、点击节点或首行右侧的 e 提示 |
| 树展开 / 折叠 | `→` / `←`，或 `Enter`；当前树节点与列表范围一致时，按 `→` 直接聚焦资产列表，无需再按 Enter | 点击节点 |
| 从列表返回树 | `←` 返回当前列表对应的节点，展开其父级并定位；不改变查询与列表选择 | 点击节点区 |
| 已加载节点统一展开 / 折叠 | `z` 分级折叠 / 展开；`+` / `-` | 点击树头 `− z` / `+ z` |
| 刷新树 | `u` | 点击树头 `↻ u` |
| 调整 / 隐藏树 | `<` / `>`；`Ctrl+B` 隐藏 / 恢复 | 拖动树的右边框 |
| 切换语言 / 阅读长文本 | `F6` 打开后用 `1`–`9` 直接切换，也可用方向键和 Enter；`F4` 阅读全文 | 点击顶部语言入口 |
| 搜索 | `/` 或 `Ctrl+F` 聚焦（聚焦时隐藏前置文案，光标为闪烁竖线）；`Ctrl+U` 清空输入；`Enter` 提交搜索；`↓` 进入列表 | 点击搜索框 |
| 刷新当前资产列表 | `F5`，或 Tab 聚焦刷新按钮后 Enter | 点击搜索框右侧 `↻ F5` |
| 资产 / 账号滚动 | `↑↓`、`PgUp/PgDn`、`Home/End` | 垂直滚轮 |
| 表格水平滚动 | 资产列表用 `Shift+←` / `Shift+→`，`→` 也可向右滚动 | 水平滚轮，或 `Shift+滚轮` |
| 打开资产 / 连接账号 | 选中行后 `Enter` | 双击行 |
| 资产翻页 | `[` / `]` | 点击上页 / 下页 |
| 账号弹层控件 | `Tab` / `Shift+Tab` 在账号、协议（多协议时）、取消按钮间循环 | 点击对应控件 |
| 选择协议 | `Enter` 打开，方向键选择，`Enter` 确认 | 点击协议选择器 |
| 返回 / 关闭弹层 | `Esc`：先关闭展开的下拉菜单，再关闭弹窗，恢复原焦点 | 点击关闭 |
| 切换窗口 | `W` 聚焦窗口栏，`←→` / `Home/End` 选择，`Enter` 切换 | 点击窗口标签 |
| 刷新 / 重试加载 | `R` | 点击树头 `↻` |
| 退出登录 | `Q` / `Ctrl+C` | 有会话时弹出断开确认 |

连接终端内，普通按键直接交给远端程序，包括 `Ctrl+C`、`Esc`、`Tab`、`F10` 和 `q`。窗口管理使用两步快捷键：先按 `Ctrl+]`，再按下表中的键。

| 第二个键 | 行为 |
| --- | --- |
| `0` | 返回资产面板，保留所有会话 |
| `1`–`9` | 按会话顺序切换 |
| `N` / `P`，或 `→` / `←`，或 `Tab` / `Shift+Tab` | 下一个 / 上一个窗口 |
| `W` | 聚焦窗口栏；`Tab` 可进入返回资产、断开按钮，再回到终端 |
| `?` / `H` / `F10` | 显示帮助；关闭后回到原控件 |
| `L` | 切换 TUI 语言，保留远端会话 |
| `A` | 切换深浅主题与强调色，保留远端会话 |
| `Q` | 退出确认；默认选中返回，可用 Tab / Shift+Tab 和 Enter 操作 |
| `X` | 断开并关闭当前会话 |
| `Esc` | 取消窗口管理操作 |
| 再按 `Ctrl+]` | 向远端发送原始 `Ctrl+]` |

工作区的 Tab 焦点依次经过窗口栏、主题、语言、组织（仅企业版）、树类型下拉、树、折叠与刷新按钮、搜索、列表刷新按钮、资产表格、分页按钮（多页时）。弹窗内焦点不会离开弹窗；帮助可叠加在账号弹窗上并滚动阅读，关闭后保留原选择和焦点。会话工具栏中按 `Esc` 返回远端输入，普通 `Tab` 在远端终端内仍用于补全。底部根据宽度用一至两行显示当前步骤的常用操作，当前可执行的快捷键收进 `F10` 帮助，72 列终端也能找到帮助入口。

快捷键可用状态与实际分发共用 `tui_shortcuts.go` 中的当前上下文定义。区域、按钮和常用页脚快捷键始终保留文字与占位：可用时使用主题色加粗，不可用时使用普通灰色。输入搜索、展开下拉、打开弹窗不会增删其他区域的提示文字或改变其宽度；普通字符仍优先输入当前控件。搜索框的 `/ 搜索` 前缀仅在聚焦时隐藏，失焦后恢复，不改变其他区域布局；搜索光标使用终端原生闪烁竖线，离开搜索或退出 SSH 恢复默认形态；只按 Enter 提交搜索。远端输入期间区域按钮保留字母提示并变灰，先按 `Ctrl+]` 进入窗口命令模式后重新高亮，字母不会直接拦截远端 Shell。页脚常用提示固定顺序，最多两行，窄屏按完整提示裁剪；远端输入和窗口命令模式显示各自命令。帮助中列出的命令可直接执行，执行后关闭帮助并回到原控件。

也可以直接点击窗口标签，或点击会话中的「返回资产 / 新建连接」。返回资产页后可以继续搜索和建立其他连接。树、查询、分页、行选择和滚动位置保持原样。每次切换组织或树视图会重新加载对应范围；不会跨组织沿用资产结果。

最多同时保留 9 个会话，包括等待审批、已结束但未关闭、正在断开的会话。会话边框右上角的复制、断开、全屏按钮按文字宽度紧凑排列，按钮之间用 `·` 分隔；全屏仅保留退出全屏。每个会话有自己的输入、输出、屏幕、上下文和窗口尺寸；切换标签不终止会话。关闭某个会话只取消该会话；退出 SSH 登录会关闭全部会话。

下拉组织、树类型和协议选项前显示序号，可在控件聚焦后或下拉打开时直接输入数字选择；多位序号支持连续输入，存在前缀歧义的单个数字在 450 毫秒后确认，也可按 Enter 立即确认，切换焦点或取消菜单会撤销待确认输入。名称输入筛选仍保留。区域键在账号等弹窗内保留占位并变灰，远端终端仍保留原始 F1–F3，窗口操作使用 Ctrl+]。

具体组织下，三种树的 API 第一级节点默认展开一层，随着可见区域逐个获取子节点，后代不递归展开；全局组织下授权树的组织根节点默认收起。全局组织复用带用户 ID 的授权树、资产、收藏与计数接口，只聚合该用户所属组织中的授权数据。账号查验及后续连接、ACL、审批使用资产真实所属组织，不能把全局组织 ID 当成资产所属组织。

## 实现与数据范围

`pkg/handler/server_ssh.go` 接入新的普通 PTY 登录入口。直接资产登录、非 PTY 命令、SFTP 继续走原有入口。普通 SSH 登录只提供 TUI，不保留逐行菜单、列表和回退入口。空 TERM、`TERM=dumb`、无法识别或不支持光标定位的终端会收到明确提示并以非零状态退出；不会输出 TUI 控制序列。

`internal/tui/ssh.go` 将 SSH channel 适配成 tcell Tty。只有一个读取器消费登录流；使用客户端声明的 TERM 和 SSH window-change 事件，不读取服务端 `/dev/tty`，不改进程级 TERM。常见终端描述随二进制打包，包括 xterm、screen、tmux、Linux console、Alacritty、Kitty 和 Ghostty。已有鼠标能力的客户端可使用鼠标；无鼠标协议的客户端仍能使用完整键盘流程。

服务正常停机或重启时，SSH 服务先通知所有 TUI 退出，待鼠标、粘贴和备用屏幕模式恢复后结束 SSH 会话；停止期间不再启动新的 TUI。终端恢复必须在连接仍可写时完成。断网、强制杀死 SSH 客户端或 `SIGKILL` 会使恢复指令无法到达客户端，此时可在本地执行 `reset` 恢复终端。

真实 SSH 停机对比已验证：旧版收到 SIGTERM 后，1000/1002/1003/1006 鼠标模式以及 2004 粘贴、1049 备用屏幕仍开启；修复版在连接结束前全部关闭。自动化回归同时检查这些模式的最终状态和服务停机通知能结束已有 TUI。

`pkg/handler/tui_data.go` 使用现有 Core API：

- 组织功能：异步读取公开设置，与 Web 导航保持一致，仅在 `XPACK_ENABLED` 且 `XPACK_LICENSE_IS_VALID` 时显示组织。社区版以及未启用企业许可的环境直接在默认范围加载资产和树，不枚举组织、不验证组织成员，也不保留隐藏组织控件的快捷键和 Tab 焦点。读取设置失败时提示重试，不猜测版本。
- 组织（企业版）：在服务端分页查询组织，再通过该组织范围内的用户列表核验当前用户 ID，每次最多并发 4 个成员检查。第一个通过验证的组织立即打开树和资产，剩余成员检查在独立队列中继续，选择器显示「加载中」；完成后按 Core 原顺序补齐选项，保留当前组织、查询和行选择。只有通过成员验证的组织才进入 UI。组件角色没有 RBAC 查询权限，因此不读取 org-role-bindings，也不把组件账号可见组织直接呈现为用户组织。组织枚举上限 1000。
- 授权树：与 Lina 使用相同的 `parent_key` / `node_cursor` 请求，每页最多 100 个节点。展开时取首批子节点，键盘或鼠标滚动至已加载子树末尾前 20 行时预取下一页；失败可在「加载更多」行按 Enter 重试，不循环自动重试。当前视图最多保留 5000 个节点；重复节点 / 游标不会导致无限请求，折叠后的迟到响应不会重新展开节点。
- 类型树：与 Lina 相同，分类接口一次返回类别 / 类型 / 平台结构及标签内数量，根节点合计类别数量；不对固定分类伪造分页。资产列表携带 category / type / platform 过滤。
- 收藏树：与 Lina 相同，使用用户收藏树接口，按 `parent_id` 展开获取一层文件夹；当前 Core 此接口没有服务端分页游标。对应 `folder_id` 下的资产使用分页列表。此版本展示现有收藏，不新增收藏编辑功能。
- 数量：授权和收藏都使用 Lina 的 `tree-metrics/` 批量接口，分别传 `authorization` / `favorite`，显示用户有权访问的数量；包含未分组、收藏根与零数量。独立工作队列每批最多 100 个资源；仅为已展开结构分批获取，随着滚动越过半批边界继续下一批。已完成的数量复用，刷新 / 切换组织或树后重新加载；数量请求不阻塞节点和资产列表。
- 资产：每页 50 条；当前组织、节点、类型或收藏范围加搜索条件一起送至 Core。
- 账号：重新查询用户可连接资产详情、授权账号与协议，校验详情的资产和组织。匿名账号不显示。

每次请求创建独立 API 客户端副本并设置组织和语言，不修改共享客户端。SDK 的副本各自创建 HTTP Transport，因此这些临时客户端使用 `Connection: close`，避免每次组织查询遗留一个不能复用的空闲连接。五个数据工作队列分别处理组织、树、数量、资产和账号；每个队列只保留一个待执行请求。搜索仅在 Enter 后提交；输入草稿与已提交条件独立保存，输入期间不清空列表或发送搜索请求。用请求代次丢弃旧搜索、旧组织或同一节点的过期响应；替换树节点时扣除旧节点计数。SDK 不提供单次请求 context 取消，进行中的请求受 SDK HTTP 超时约束，结束后会丢弃失效结果。

界面支持中文、繁体中文、英语、日语、葡萄牙语、韩语、俄语、西班牙语和越南语，三种树的名称在所有语言中均包含“树”的对应词。`F6` 仅切换当前 SSH 工作区语言，保留组织、查询和已有远端会话；重新读取当前树以更新服务端翻译。语言弹窗在名称前显示数字，仅选中行有突出背景；未选中行保持面板底色。下拉菜单、树节点和表格长文本可用 `F4` 阅读全文。

空节点计数依赖 Core 的修复：`apps/perms/utils/user_asset_tree.py` 在读取完全授权节点的计数时使用 `fully_granted_counts.get(node.key, 0)`。原逻辑会因空节点未出现在计数字典中触发 `KeyError`，使整批数量请求失败。此修复需要随 Koko 一起部署；真正失败的数量请求仍显示未知状态，不伪装为零。

## 远端终端与连接流程

`pkg/handler/asset.go` 中的 `connectSelectedAsset` 在 TUI 会话内执行凭证、动态用户名、ACL 拒绝 / 审批、SSH 证书清理和代理流程。权限、审计与远端会话超时仍由原有 proxy 执行。ACL 确认、等待审批及结果都在对应会话窗口内完成，等待时可以切换标签或返回资产。审批结束仅停止当前审批输入读取并等待进度输出结束，保留会话上下文供后续连接使用，避免关闭 TUI 会话或抢占 Shell 输入。拒绝或取消后在该标签保留结果；人脸验证仍沿用现有 WebTerminal 提示。

`internal/tui/terminal.go` 将远端输出交给 libghostty 解析为带颜色和样式的字符单元，再绘制到独立会话窗口。支持 ANSI 光标控制、主 / 备用屏幕、中文双宽字符、终端按键模式、括号粘贴及应用鼠标模式。远端程序收到窗口内部的 PTY 尺寸，激活标签或调整终端大小时更新。普通输出不会清除资产工作区。

每个会话最多 200 行模拟器回滚存储，输入队列上限 64KiB，超过上限会取消该会话，避免静默截断命令。禁用 Kitty 图片存储和本地文件 / 共享内存加载。远端数据引起的绘制请求合并为最多每秒 20 次；数据请求和终端会话数量均有上限。

终端中的图形协议、客户端原生新窗口、断开 SSH 后恢复会话、滚轮浏览本地回滚历史不在本版范围。鼠标滚轮在会话内按远端程序启用的鼠标协议转发。关闭后保留结束画面，直到关闭标签。
